# Courses at BrightPath Academy

BrightPath Academy is an education-counselling institute that helps students choose and prepare for career programmes.

## Data Science Programme
A 6-month programme covering Python, statistics, machine learning and a capstone project. Classes run on weekday evenings, with weekend doubt-clearing sessions. Placement support is included.

## Web Development Programme
A 4-month programme covering HTML, CSS, JavaScript, React and a backend with Node.js. Students build three portfolio projects.

## IELTS Preparation
An 8-week coaching programme with mock tests, speaking practice and personal feedback. Small batches of ten students.
